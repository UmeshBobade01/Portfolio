# Portfolio Website

A personal portfolio webpage for `Umesh Bobade`, built with HTML, CSS, and JavaScript. The page highlights skills, internship experience, education, projects, certifications, and contact information.

## File

- portfolio.html

## Features

- Responsive single-page layout
- Custom animated cursor
- Smooth scroll behavior
- Sticky navbar with scroll effect
- Back-to-top button
- Scroll reveal animations
- Skills, experience, education, projects, certifications, and contact sections

## Built With

- HTML5
- CSS3
- Bootstrap 5
- Bootstrap Icons
- Google Fonts
- Vanilla JavaScript

## Usage

1. Open portfolio.html in a web browser.
2. Ensure internet access for CDN assets:
   - Bootstrap CSS and JS
   - Bootstrap Icons
   - Google Fonts

## Notes

- The page uses inline CSS and JavaScript.
- Interactive elements and animations are handled with vanilla JavaScript.
